**What is this?** The place to collaborate on an open-source implementation of the [Java Platform](https://www.oracle.com/technetwork/java/javase/overview/index.html) and related projects.

![Duke plugging](images/duke-plug.png)

**Download** and install the [latest open-source JDK](projects/jdk/27). Oracle’s free, GPL-licensed, production-ready OpenJDK JDK 27 binaries for Linux, macOS, and Windows are available at [**jdk.java.net/27**](https://jdk.java.net/27); Oracle’s commercially-licensed JDK 27 binaries, based on the same code, are [here](https://www.oracle.com/java/technologies/downloads/).

![Duke chalkboard](images/duke-chalkboard.png)

**Learn** about the key active Projects in the Community including [Amber](projects/amber) (high-productivity language features), [Babylon](projects/babylon) (foreign programming models), [Leyden](projects/leyden) (better startup and warmup), [Loom](https://wiki.openjdk.org/display/loom/Main) (lightweight concurrency), [Panama](projects/panama) (foreign functions and foreign data), [Valhalla](projects/valhalla) (primitive types and specialized generics), and, of course, [the next version of the Java Platform and the JDK](projects/jdk/28).

If you want to learn how to use Java features that are available today, head over to [**dev.java**](https://dev.java).

![Duke hacking](images/duke-pipes.png)

**Hack** on the JDK itself, right here in the OpenJDK Community: [Browse the code](https://github.com/openjdk/jdk) on the web, [clone a repository](/guide/#cloning-the-jdk) to make a local copy, and [contribute a patch](/contribute/) to fix a bug, enhance an existing component, or define a new feature.
