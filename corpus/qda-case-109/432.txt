# Comfortable visual designer and powerful code

[![3D game in editor](images/feature_size/impressive_castle_editor.webp)](features#_visual_editor "3D game in editor")

## [Visual editor](features#_visual_editor)

Design 3D and 2D games and user interfaces (with automatic scaling, anchors). Build and deploy the same project for multiple platforms. Integrate with various IDEs ([Visual Studio Code](vscode), [Lazarus](lazarus), [Delphi](delphi)...).

[![Terrain with water and trees](images/feature_size/terrain_component_1.webp)](features#_viewport_with_scenes_camera_navigation_and_other_components "Terrain with water and trees")

## [Components](features#_viewport_with_scenes_camera_navigation_and_other_components)

A lot of components to design [viewport](viewport_and_scenes) contents (3D and 2D world, using scenes, cameras, navigation, primitives, lights...) and [user interface](user_interface) (buttons, images, labels...).

[![Village scene with outlines in glTF from Sketchfab ( https://sketchfab.com/3d-models/ftm-0970f30574d047b1976ba0aa6f2ef855 by Luis Fernandez )](images/feature_size/gltf_village_outlines.webp)](features#_data_formats "Village scene with outlines in glTF from Sketchfab ( https://sketchfab.com/3d-models/ftm-0970f30574d047b1976ba0aa6f2ef855 by Luis Fernandez )")

## [Lots of ways to define data](features#_data_formats)

Use 3D models, 2D animations, sprite sheets. Great integration with authoring tools like [Blender](blender) or shops like [Sketchfab](sketchfab) thanks to using open standards like [glTF](gltf) and X3D.

[![Real-time water with caustics, reflections, shadows](images/feature_size/barna29_nice_shadows.webp)](features#_graphic_effects "Real-time water with caustics, reflections, shadows")

## [Graphic effects](features#_graphic_effects)

Composable shader effects, shadows, mirrors, physically based rendering, bump mapping, gamma correction...

[!["Escape from the Universe" on Nintendo Switch](images/feature_size/nintendo_switch_3.webp)](features#_cross_platform ""Escape from the Universe" on Nintendo Switch")

## [Cross-platform](features#_cross_platform)

Target any platform (desktop: Windows, Linux, macOS, FreeBSD, Raspberry Pi, mobile: Android, iOS, console: Nintendo Switch, web). Work on any desktop platform. VR is coming as a next target soon.

[![FPC and Delphi](images/feature_size/combined_fpc_delphi.webp)](features#_native_and_fast_code_using_modern_pascal "FPC and Delphi")

## [Clean and fast code](features#_native_and_fast_code_using_modern_pascal)

Native clean object-oriented programming language with [modern Object Pascal](modern_pascal). Fast builds, fast execution out-of-the-box.

[![Open-source, Jenkins, Docker, Codeberg, Woodpecker CI, GitHub Actions, GitLab CI](images/feature_size/combined_osi_ci_logos_2.webp)](features#_build_tool_and_continuous_integration "Open-source, Jenkins, Docker, Codeberg, Woodpecker CI, GitHub Actions, GitLab CI")

## [Open source and friendly to continuous integration](features#_build_tool_and_continuous_integration)

Tooling friendly to continuous integration. [Command-line build tool](build_tool) and [Docker](docker) image. Ready files and documentation how to use with [GitHub Actions](github_actions), [GitLab CI](gitlab_ci), [Jenkins](jenkins), [Woodpecker CI](woodpecker) or any [other CI](ci). Engine is completely open-source and [can be used to make any (including proprietary) applications](license).
