## A different way to make games

![](/assets/home/features/innovative.webp)

#### Innovative design

Godot's Node and Scene system gives you both power and flexibility to create anything.

![](/assets/home/features/language.webp)

#### Use the right language for the job

Keep your code modular with an object-oriented API using Godot's own GDScript, C#, C++, or bring your own using GDExtension.

C# support is currently only available for desktop and mobile platforms as of Godot 4.2.  
Use Godot 3 to run C# on the Web platform.

![](/assets/home/features/2d.webp)

#### Dedicated 2D engine

Make crisp and performant 2D games with Godot's dedicated 2D rendering engine with real 2D pixel coordinates and 2D nodes.

![](/assets/home/features/3d.webp "Screenshot from the game 'Human Diaspora'")

#### Simple and powerful 3D

Godot's 3D nodes give you everything you need to build, animate, and render your 3D worlds and characters.

![](/assets/home/features/xr.webp "Screenshot from the game 'Penguin Festival'")

#### Exemplary XR support

Godot has built-in support for OpenXR and WebXR, and supports various other XR SDKs through plugins.

![](/assets/home/features/cross-platform.svg)

#### Release on all platforms

Deploy your game on desktop, mobile, and the web in seconds. Godot even supports consoles through third party publishers.

![](/assets/home/features/oss.svg)

#### Open Source

Truly open development: anyone who contributes to Godot benefits equally from others’ contributions.

[Learn more about using Godot](/features/)

## Get involved

Join the community and help create a game engine that belongs to everybody.

![](/assets/home/code.svg)

#### Code

If you know how to code, you can help by fixing bugs and working with engine contributors towards the implementation of new features.

[Learn more](https://contributing.godotengine.org/en/latest/ways_to_contribute/development.html#contribute-engine-code)

![](/assets/home/document.svg)

#### Document

Documentation quality is essential in a game engine; help make it better by updating the API reference, writing new guides or submitting corrections.

[Learn more](https://contributing.godotengine.org/en/latest/ways_to_contribute/development.html#contribute-documentation)

![](/assets/home/report.svg)

#### Report

Found a problem with the engine? Don't forget to report it so that developers can track it down.

[Learn more](https://contributing.godotengine.org/en/latest/ways_to_contribute/feedback.html)

[![Godot Foundation logo](/assets/home/foundation/godot-foundation-logo-dark.svg)](https://godot.foundation)

You don't need to be an engine developer to help Godot. Join the [development fund](https://fund.godotengine.org/) and help us make the Godot Engine even more awesome!
